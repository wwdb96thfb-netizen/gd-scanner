Summary

What changes, and what stays

  • Stays the same: the Coast Guards green, the boat banner, the two typefaces already in the app (so it still works offline), and the three decision colours.
  • Becomes consistent: one set of sizes for text, spacing, corners and shadows, used in both apps. Today the phone and the Mac use slightly different greens, reds and ambers; this fixes one set for both.
  • Easier outdoors: body text goes from 15 to 16, every tap target is at least 48 pixels, the Release / Detain / Seize buttons grow to 56, and the main action sits where the thumb reaches.
  • One icon style: simple outline icons, all drawn the same way, replacing today's mix of coloured pictures.
  • One vocabulary: each thing has one name everywhere (for example "case", never "file" or "scan").

Use the Auto / Light / Dark switch at the top to see every part in both modes.

Colour

Brand and neutrals

Green is the brand and the colour of the main action. Greys lean slightly green so the whole app feels of one piece. Colour is never the only signal: every coloured state also has a word.

Decision colours

Release, Detain, Seize: the same everywhere

These three colours mean only these three decisions. They are not used for anything else, so a soldier never has to wonder what a colour means. The strong colour is for buttons and stamps; the soft version is for chips and highlights.

Release#17854a

Kept exactly from the phone app. The Mac control room currently uses slightly different shades (#15803d, #d97706, #b91c1c); these three replace them so both match.

Amber needs big, bold text. White text on amber is only readable at large bold sizes, so decision buttons always use 18-pixel bold capitals.

Type

Two faces, eight sizes

Barlow Semi Condensed for headings, stamps and decision words: narrow and strong, it fits long words on a small screen. Inter for everything else: clear at small sizes. Both are already in the app's fonts folder and work offline. No other sizes are used.

Touch and reach

Built for a thumb, outdoors

Hard to reach: information onlyEasy reach:
main action and tabs

Do

  • Every tap target at least 48 × 48
  • Decision buttons 56 high
  • 8 or more between targets
  • The one main action at the bottom of the screen
  • Strong contrast that still reads in sunlight

Avoid

  • Small text links as the only way to act
  • Two dangerous buttons side by side
  • Important actions at the top corners
  • Grey text for anything that must be read

Buttons

One main action per screen

Kinds

Main (green, filled): the one thing to do next. Secondary (outlined): other choices. Danger (red outline): removes or stops something. Text link: small, rare actions.

States

While working the button shows a spinner and its own word ("Sending"). A disabled button always has a line nearby saying why.

Decision buttons

Two taps to decide: the first tap turns the button into "Confirm detain?" with a ring; the second records it. After 5 seconds it goes back. This is how both apps work today; it stays.

Empty, loading, errors

Loading

Grey shapes the size of what is coming, instead of a blank screen.

Error message pattern: what happened, in plain words; then what to do. Never "Error 401", never "Something went wrong".

Icons

One outline style

All icons are drawn on the same 24-pixel grid with the same line thickness and rounded ends. They always sit next to a word, except in the bottom tab bar where the word is underneath.

Write like this

  • Buttons start with a verb, three words at most: "Send case"
  • Confirmations say what happened: "Seize recorded. The post has been told."
  • Errors say what to do next
  • Numbers as digits: "3 cases"
  • Dates as 12 Oct, 08:42

Not like this

  • "Please", "successfully", "kindly"
  • Technical words: server error, request, sync
  • Long sentences on buttons
  • Two names for one thing
  • Capitals for whole sentences

Phone and Mac

Same parts, different frame

The phone keeps the bottom tab bar and one column. The control room keeps the left menu and a wider grid. Colours, type, chips, buttons and words are the same in both.
